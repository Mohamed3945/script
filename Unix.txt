======================================================================
1. DEFINITIONS DE BASE
======================================================================

1.1 VM (Virtual Machine)
Une VM est une machine virtuelle.
C’est un ordinateur distant qui tourne sur un serveur physique.
Tu y accèdes comme si c’était une machine normale, mais à distance.

1.2 Machine locale vs machine distante
- Machine locale : ton PC
- Machine distante : la VM
Quand tu es connecté en SSH, les commandes s’exécutent sur la VM.

1.3 SSH
SSH = Secure Shell
C’est le protocole de connexion sécurisé qui permet d’ouvrir un terminal sur la VM.

Exemple de connexion :
ssh utilisateur@serveur

1.4 Shell
Le shell est l’interpréteur de commandes.
Il lit ce que tu tapes et exécute les commandes.
Les shells courants :
- bash
- sh
- zsh

1.5 Prompt
Exemple :
[goldenscriptadm@cr2sx29362 ~]$

Interprétation :
- goldenscriptadm = utilisateur
- cr2sx29362 = machine
- ~ = dossier personnel
- $ = utilisateur standard
- # = super utilisateur root

4. DOSSIERS IMPORTANTS SOUS LINUX
======================================================================

/               = racine du système
/home           = dossiers utilisateurs
/home/user      = home d’un utilisateur
/tmp            = fichiers temporaires
/opt            = applications installées manuellement
/etc            = fichiers de configuration
/var            = données variables
/var/log        = journaux système
/var/www        = fichiers web
/usr            = programmes et bibliothèques
/bin            = commandes de base
/sbin           = commandes système
/dev            = périphériques
/proc           = informations système et processus
/root           = home de root

5. MANIPULATION DES FICHIERS ET DOSSIERS
======================================================================

5.1 Créer un fichier vide

5.2 Créer un dossier

5.3 Créer une arborescence
mkdir -p /tmp/monapp/backend

5.4 Copier un fichier

Exemple :

5.5 Copier un dossier

5.6 Déplacer un fichier

5.7 Renommer un fichier

5.8 Supprimer un fichier

5.9 Supprimer un dossier

5.10 Supprimer de force

ATTENTION :

8. EDITEURS DE TEXTE
======================================================================

8.1 nano
Simple pour débuter

Raccourcis principaux :
- Ctrl + O : sauvegarder
- Entrée : confirmer
- Ctrl + X : quitter

8.2 vi / vim
Souvent déjà installé

Bases minimales :
- i      : passer en insertion
- taper le texte
- Esc    : sortir de l’insertion

12. DROITS ET PERMISSIONS
======================================================================

12.1 Voir les droits
ls -l

Exemple :
-rw-r--r-- 1 user group 123 Aug 26 test.txt

12.2 Interprétation
- premier caractère :
  - = fichier
  d = dossier
- ensuite groupes de 3 :
  rwx rwx rwx
  utilisateur / groupe / autres

r = lecture
w = écriture
x = exécution

12.3 Rendre exécutable
chmod +x script.sh

12.4 Changer propriétaire
chown user:group fichier

Exemple :
sudo chown -R www-data:www-data /var/www/monapp

23. CLEFS SSH - NOTION DE BASE
======================================================================

SSH peut fonctionner :
- avec mot de passe
- avec clé publique / privée

Dossier courant des clés :
~/.ssh

Fichiers typiques :
- id_rsa
- id_rsa.pub
- authorized_keys

Important :
- la clé privée ne se partage jamais
- la clé publique peut être déposée sur le serveur

26. BONNES PRATIQUES EN ENVIRONNEMENT D’ENTREPRISE
======================================================================

- Toujours savoir sur quelle machine tu es
- Toujours vérifier ton dossier courant avec pwd
- Toujours lister avant de supprimer
- Utiliser sudo seulement si nécessaire
- Ne pas modifier /etc sans comprendre
- Garder une trace des changements
- Ne pas stocker de secrets en clair dans des scripts
- Vérifier l’espace disque avant déploiement
- Vérifier les logs après un changement
- Utiliser des répertoires dédiés à l’application

======================================================================

/var/www/monapp/
/etc/nginx/
/etc/systemd/system/

Interprétation :

- /opt/monapp/logs/     : logs applicatifs
- /var/www/monapp/      : frontend statique
- /etc/nginx/           : configuration reverse proxy
- /etc/systemd/system/  : fichiers de service
